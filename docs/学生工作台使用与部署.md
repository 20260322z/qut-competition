# 青理竞赛通 2.1 学生工作台

2.1 是 iOS 风格的原生安卓界面更新，使用已部署的 2.0 后端。安装同签名新版 APK 可覆盖升级，无需卸载旧版；卸载会删除仅在本机保存的数据。

这次升级基于用户确认的 `20260322z/qut-competition`，保留原有竞赛采集、QQ 通知、Java 综测和团支书管理端。

## 从哪里开始

底部有首页、学业、竞赛、升学、我的。第一次可以先在我的→个人信息与目标里填写学校、专业和目标。无需邮箱登录即可使用本机成绩、档案、计划、简历编辑、文字面试练习和打印打包；投稿、组队、云端文件和邮件需要邮箱登录。

首页将常用功能集中为八宫格。公共资料、私人文件和打印准备统一进入“资料中心”，通过页面上方三个选项切换；也可以从升学页直接进入私人文件。五个底部入口保留，相关功能集中在各自主页面。

首页展示个人方向、未完成任务、收藏竞赛的临近截止及学业概览。任务和申请由本人确认进展，软件不会自动代替你向学校报名或提交申请。

## 成绩

在学业→成绩选择导入 CSV 或粘贴内容。文件表头必须是：

```csv
学期,课程,学分,成绩,绩点,状态
2026-1,高等数学,4,88,3.8,正常
2026-1,大学英语,2,,,未发布
```

上面只是格式示例，不会预装成用户成绩。先预览新增、变化和未变记录，再确认合并。同一学期同名课程重复会阻止保存，原有其他课程不会删除。原文会作为本机导入记录留存。等级成绩、补考和重修先按学校规则核对；软件不猜学校的分数转绩点公式。

加权成绩和绩点均按课程学分计算，并显示统计范围。未发布成绩不当成零分；缺失绩点单独显示统计覆盖学分。目标试算只是一种数学测算，不修改成绩，不预测录取。

新增本人教务成绩预览接口 `/app/academic/transcript`，复用综测学生登录身份，并再次核对教务账号为本人。需先更新 Java 后端。学校真实页面、验证码和当前账户是否能返回完整成绩，仍需真实账号联调；遇到失败不会覆盖本机成绩，可继续使用 CSV。原有学生登录要求班级已由团支书建立，未改变该规则。

## 邮箱

我的→账号与同步：输入邮箱，接收 6 位验证码，10 分钟有效。我的→邮箱提醒：单独验证收件邮箱，然后主动开启提醒。邮箱身份不是在校生认证。修改收件邮箱必须先验证新地址，不需要你的 QQ 邮箱密码。

新竞赛支持每小时或每天汇总，分类和关键词的关系为组内任选、组间同时满足。启用前的历史通知不会补发。没有新内容不会发送空摘要。

通知详情可以设置提前一天或三天的云端邮箱提醒，官方日期更新会调整相对提醒。邮箱页也可设置未来绝对时间的自定事项。任务必须显示已在云端保存，才能由服务器在 App 退出后继续处理。

系统通知和邮箱是两个独立渠道。拒绝安卓通知权限不会阻止浏览或邮件订阅。邮件发送状态 `submitted` 只表示发信服务器接受，不保证到达收件箱；`uncertain` 表示网络中断使结果不确定，为防止重复，不自动重发。关闭或解绑会取消排队邮件，已经发出的邮件不能撤回。

## 竞赛与组队

目录包含 84 项，来自锦州医科大学教务处公开发布的 2023 年目录，保留名字、年份和来源，不能当作 2026 年学院综测认定清单：
https://jwc.jzmu.edu.cn/info/1207/1532.htm

从目录可进入同一赛事的组队筛选。公开浏览招募与经验不要求登录；申请、投稿、评论需要邮箱登录。队长录用后，申请人需在 48 小时内确认，预留名额期间不会再被他人占用。退出队伍释放名额；队长可移交给已入队成员。队内成员可以维护任务状态。

经验支持正文、评论、帮助/收藏和举报。管理员通过服务器命令处理举报并隐藏帖子或取消文件公开。首版没有虚构用户、活跃数或获奖经验。

## 档案、升学、简历与面试

成长档案记录角色、真实贡献、成果和证明文件版本。目标院校、申请批次、材料清单、学习任务均能新增、修改、删除和导出文字清单。需要核对的要求应填写官方网址，个人备注与官方要求分别填写。

简历工作室可以选择档案复制到初稿，原档案不改变。保存会建立新的本机版本，旧版可以加载为编辑副本。向 DeepSeek 提交前需要预览并主动勾选授权；模型只接收界面上显示的正文和目标。逐段展示原文、修改建议和原因，由本人采用并再编辑。结果需要自行检查事实，AI 不替代事实证明。离线可导出 DOCX 和 PDF。

面试有 5 题和 10 题文本练习，可保存、跳过、提前结束、删除已保存回答。可以单独提交当前问题和回答获取 AI 反馈。语音面试和付费系统未加入本版。

## 文件与打印

单文件 10 MB，个人空间 200 MB。上传默认私有；主动公开前需确认授权和隐私。相同内容重复上传返回原记录，不偷偷改变原分享状态。取消分享后新的公开下载停止，已被他人下载的副本无法远程撤回。

打印准备可以选 1—20 个文件、排序、设置份数、页码、单双面、色彩和装订，再导出 ZIP 文件与文字清单。最多 50 MB 总文件，原件不修改。此功能还没有商家、支付、订单和物流；导出的清单不是实际订单。

## 后端更新

现有 `/data` 数据卷保留，新增表采用 `CREATE TABLE IF NOT EXISTS`，不会删除旧通知。工作台文件放在同一卷的 `/data/student-files`。部署前先备份数据库、该文件目录及当前镜像。

把 `docs/student.env.example` 中需要的配置加入服务器现有 `.env`。`SMTP_PASSWORD` 填平台发信账号的 SMTP 授权码，不是学生收件邮箱密码。未配置 SMTP 时，验证码接口明确返回未配置；已配置的 DeepSeek key 可继续使用。禁止把 `.env`、签名和数据库提交到公开仓库。

```bash
cd /opt/qut-competition
docker compose exec -T api python -m app.manage backup --output /data/before-student.db
docker compose up -d --build api
# 需要教务成绩预览接口时再更新独立综测服务：
docker compose up -d --build zhcp-api
```

服务器若使用独立 Compose 命令，替换为 `/usr/local/bin/docker-compose -p qut-competition -f compose.yaml`。不要操作其他已有的 `ruoyi-admin-docker`。

```bash
docker compose exec -T api python -m app.student_manage reports
docker compose exec -T api python -m app.student_manage resolve-report --id 举报ID --decision 已处理 --hide
docker compose exec -T api python -m app.student_manage mail-tick
```

邮件调度 30 秒检查一次，AI 队列 10 秒检查一次；保持一个 Uvicorn worker（Dockerfile 已如此设置）。进程中断时已经开始的邮件提交结果可能不确定，不自动重复发送。数据库备份外，还要备份 `student-files`，否则只能恢复文件记录而无法恢复文件内容。

## 当前边界

本版完成基础工作台和主要可运行流程，并不等于 Word 所有后续细节全部交付。已补齐院校对比、组队成果分发确认、站内消息与作者屏蔽、本机草稿、云端冲突选择。尚未完整实现：正式学院绩点规则包、综测与成长档案的双向证据关联、帖子图片和版本历史、文件版本替换与应用内离线预览、复杂 PDF 合并与签章检查、细分目录条件。原有综测界面和 Excel 导出继续沿用。

真实 SMTP 发信、DeepSeek 输出质量及学校账号读取需要具备对应配置/账号才能联调；接口模拟测试通过不能替代这些验证。公网原地址是 HTTP，涉及私人资料的正式使用应配置 HTTPS 后在设置里切换。

2026-09-11 部署更新：经用户授权接受本次展示的 SSH 指纹后，连接时固定校验该 ED25519 指纹，未覆盖本机旧 SSH 记录。这是用户授权接受新身份，并不表示已经完成独立控制台核实。竞赛 API 与 Java 综测后端均已升级到 2.0.0，原有 106 条通知保留，API 重启后数据完整性检查通过，原团支书管理页面继续可用。公开服务地址仍为 `http://38.207.179.218:18086`，现有 APK 不需要更换地址。

平台 QQ 发信邮箱已配置，真实 SMTP 登录认证通过；发信授权码只保存在服务器私有 `.env` 中。学生在“我的→账号与同步”输入自己的邮箱请求验证码即可开始使用；需要邮件提醒时，再到“我的→邮箱提醒”验证收件邮箱并主动开启订阅。SMTP 认证成功不代表已经验收实际邮件到达收件箱，仍需用户首次登录确认。
