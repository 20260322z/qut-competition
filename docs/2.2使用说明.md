# 青理竞赛通 2.2 智能工作台

2026 年 9 月 12 日。Android 8.0 及以上，包名 cn.qingli.competition。继续使用原发布签名，可覆盖安装旧版。

## 安装和开始使用

打开“青理竞赛通-v2.2.0.apk”，允许当前文件管理器安装应用，按提示完成安装。已有旧版时直接覆盖，不要卸载。主服务预置为 http://38.207.179.218:18086，可在“我的—设置与连接”修改。

游客可以浏览公开通知、编辑本机记录、保存简历版本并导出。云端智能任务、关注赛事、私人文件和邮件提醒需要在“我的—账号”使用邮箱验证码登录。手机没有通知权限时仍能浏览；邮箱提醒由服务器执行，不依赖 App 保持运行。

## 简历工作室

从首页常用功能或“升学—简历工作室”进入。这里单独设置工作台、编辑、智能任务、版本四页。

1. 在编辑页填写目标学校、专业、用途和篇幅。可选择成长档案里的真实经历加入正文，也可以直接粘贴已有简历。
2. 正文和目标自动保存在当前本机空间。点击“保存为本机新版本”保留一个独立版本；修改草稿不会覆盖已保存版本。
3. 在智能任务页选择全面优化、结构、目标适配或精简。检查正文预览，可以额外勾选已上传的私人 PDF、DOCX 或 TXT。
4. 确认本次材料可以交给云端 AI 后开始。处理依次经过材料核对、内容诊断、逐段修改、事实复核、交付结果；缺少事实时会暂停，最多询问三个问题。不能确认的问题可以跳过，助手只能依据已有材料继续。
5. 结果逐段显示原文、建议和原因。点击“采用到草稿”只修改当前编辑副本；原文重复或已经被改过时，改为手动核对。数字检查和另一轮事实复核用于拦截不可靠修改，仍需要本人最终确认。
6. 回到编辑页核对，再保存新版本或导出 Word、PDF。智能任务报告也可导出，包含修改对照、说明与引用。

## 面试训练营

从“升学—面试练习”进入独立页面。准备页填写目标、选择中文或英文，以及 3、5、10 题；可以选已有简历作为背景，也可直接填写自己的项目经历。

确认材料后创建一轮练习。每次只显示一道题，回答后由模型根据真实回答给出反馈并追问。没有准备好可以跳过；跳过不生成虚构回答。整轮结束后生成优点、具体问题和下一步练习事项，可修改建议任务的标题、个人计划日期后加入待办。

可以离开页面再从任务记录继续。准备材料、未提交回答在本机保存；已经提交的回答和任务进度在服务器保存。当前为文字面试，不包含语音转写、视频面试或录取概率预测。题目是练习题，不冒充学校历年真题。

## 智能任务与费用范围

首页增加统一任务中心。学业、升学、日程、资料、档案以及赛事详情中的准备、招募、经验均可创建分阶段任务。结果可以查看、导出，并在本人确认后加入待办。

当前采用 DeepSeek 的受限分阶段处理流程。模型没有报名、发帖、支付、发信或修改综测的操作权限。每次最多选择 5 个文件，默认每账号每天 12 项任务、最多 3 项排队或处理中的任务。超过限制会直接提示，不假装已经开始处理。

失败时显示当前步骤，可以从失败步骤重试；完成步骤保留。停止任务会阻止后续步骤，但已经发给模型的内容无法撤回。删除任务会删除服务器里的该任务材料快照、结果和问答，已采用到个人记录的内容仍保留。

## 赛事中心、通知和邮箱

在“竞赛—竞赛目录”搜索名称、简称或旧名，进入统一赛事详情：概览、通知、组队、经验、资料五个区域。每项具有稳定编号和独立来源地址；目录版本仍为 2023，不能据此认定本校综测加分。

84 项已建立来源档案，其中 11 项完成此次证据核对，71 项待核验、2 项为历史来源。已核验不等于已经抓到本届通知：部分站点是动态页面、历史栏目或只提供微信消息。详情会展示核验依据、最近成功检查和采集异常。未核验网站不参与官网自动采集。

校内通知按赛事身份匹配，官网通知保留原文链接及版本。校内与主办方的时间分开显示。只对一句话中明确、完整且不含歧义的截止日期建立节点；缺少年份、多个日期混在一起或缺时刻时，不猜测为确定截止。

点击关注后，再到“我的—邮箱提醒”验证收件邮箱并打开新通知、截止提醒。首次关注不补发历史新通知；已有未来截止可安排提前一天上午 9 点的邮件。这是提醒时间，不是推测出的赛事截止时刻。更正后的通知会取消旧的待发送邮件，再安排新提醒；取消关注停止未来待发邮件。

邮箱系统此前已完成 SMTP 配置，但本次未向真实收件人发送验收邮件。“已提交发信服务器”不等于进入收件箱，请结合邮箱页状态、垃圾箱和邮件服务结果判断。

## 资料、成绩与账号空间

资料列表新增“预览、阅读与智能解读”。PDF 可查看原版单页预览和提取文字；DOCX、TXT 按文字段阅读，明确区分段落与原版页码。可在文件内查找关键词、收藏并保存阅读位置、关联自己的新旧文件版本，以及将所选文件交给资料助手。扫描 PDF 可以查看原版，但没有可选文字时不会伪造 OCR 结果。

首页的“搜索工作台”可以检索赛事、已缓存通知和当前账号个人记录；点击云端搜索还能查公开/私人文件元信息、已解析正文和经验帖。文件内搜索也可直接使用。单文件 10 MB，个人空间 200 MB。公开分享继续需要单独确认；取消公开后不再允许新的公共检索和下载，已经下载的副本无法收回。

成绩保留原有教务预览、CSV 导入、加权成绩和绩点计算。新增撤销上一次导入，恢复原课程并撤回该次新增课程；如果导入后课程又被修改，系统拒绝直接撤销，防止覆盖后来的修改。没有提供原始绩点时不会用 AI 猜测补齐。

新版本的本机工作台按账号及服务器身份隔离。切换账号不会展示上一账号的新记录；退出后回到游客空间。升级前已有共享本机记录归入首次升级时的登录身份或游客空间，旧数据无法自动判定历史上分别属于谁。云端备份仍是主动操作。

综测入口、源码、计算规则、教务及学工对接、导出与后台保持冻结，未在本次升级中发布其服务。

## 维护、备份和已知边界

后端部署目录 /opt/qut-competition，API 镜像 qut-competition-api:2.2.0，仅重建 API 容器。首次升级前的备份目录为 /opt/qut-competition-backups/before-2.2.0-20260912-101541；后续修订另有时间戳备份，最新位置见验证记录中的 agent-deployment-check.json。原版 106 条通知保留。

更新后端前用 SQLite 的备份接口备份数据库，并保留 /data 中的私人文件。维护时只对 api 执行构建和 up，不对综测服务执行全栈重建。部署包中的 agent-compose.yaml 为仅 API 的示例，连接现有 qut-competition_qut-data 外部数据卷；新服务器需先创建该卷。环境配置使用服务器现有 .env，不把密码或密钥打进源码。

模型不可用时，本机编辑、版本、导出和已缓存通知仍可使用。首次真实联调简历诊断曾失败，第二次完整跑通；不能将一次成功解释为永久稳定。常见失败包括网络、模型服务和结果校验，失败记录可重试。

本次是 Word 报告的阶段性交付，仍有未完成项，详见“2.2方案对照与测试.md”。包括其余赛事来源核验、跨来源同届事件合并、完整赛道与年度结构、附件日期自动核对、队伍私有资料、全量通知云端联合检索、快捷入口自定义、语音面试、OCR、商家报价支付和订单售后。打印目前保留文件包准备，不能真实下单。
