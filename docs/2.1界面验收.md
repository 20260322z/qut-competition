## 最终模拟器验收受阻

2026-09-12 尝试安装最终紧凑版时，ADB 启动报告 `Cannot mkdir '\.android': Permission denied`。运行环境没有授予额外配置目录及网络访问权限，因此未能执行最终紧凑版的模拟器安装、5 项 instrumentation 测试和截图检查。

前一版 iOS 界面曾在 Android API 35 模拟器通过 5 项 instrumentation 测试并完成主要页面检查，但此结果不能代替最后一次紧凑布局及资料中心合并后的验收。本交付不把旧截图作为最终界面截图，旧版测试日志仅标明为历史参考。

仍需在正常的 Android 构建环境或手机上验收：覆盖安装并保留数据；首页八个工具跳转；五个底部入口；资料中心三选项及返回；搜索收藏；大字号；通知权限被拒绝后的浏览。
