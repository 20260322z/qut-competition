## 实际限制

1. 没有使用用户本人的教务密码和个人成绩进行真实学校端全流程验收。本人读取接口及权限已部署并做契约测试；第一次使用仍需由学生在综测中登录本人账号验证。学校验证码、风控、页面变化或名册条件可能阻止读取，遇到这些情况保留原成绩并提供文件导入。
2. GPA 采用原表绩点并按学分加权。补考、重修、免修等暂排除，缺失绩点不推算，不冒充学校正式排名或综测分数。
3. DeepSeek 是有网络、有额度时运行的辅助分析，知识薄弱点作为自查建议；不能凭一次成绩推断能力、排名或录取概率。
4. 共享空间是按文件分类组织的界面；尚未新增群成员、付费加入、资料交易机制。资料页面统计是已加载数量。
5. 打印可导出真实文件与清单，尚无商家接单、支付、物流和价格承诺。分页范围需核对原件，Word/PPT 页数可能随排版变化。
6. 84 项赛事继续沿用现有目录与采集状态，并非全部官网均成功采集。未增加 QQ 群信息，旧两条仍保持删除。

## 重现验证

后端：安装 requirements.txt 与 pytest 后在 backend 下执行 `pytest tests -q`。安卓在 JDK 17、SDK 35 下运行 `:app:assembleRelease :app:testDebugUnitTest :app:assembleDebugAndroidTest`，模拟器安装测试包后用 AndroidJUnitRunner 执行。签名材料单独保存，不在源码 ZIP 内。

Java 运行 `mvn package` 后，以 target/classes、target/test-classes 和 Maven 依赖作为 classpath，使用 `java -ea ... com.ruoyi.zhcp.web.AcademicSessionCheck` 执行契约检查。该检查不连接真实数据库或校园系统。
