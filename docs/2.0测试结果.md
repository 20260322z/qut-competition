## 测试中修正的问题

- 统一邮件摘要时间与数据库 UTC 时间，避免时区差异导致漏选新通知。
- 搜索回归改用通知卡片的唯一标识，避免误点具有同样标题的搜索框。
- 取消收藏提示上移；切换主页面或重新收藏时关闭旧提示，避免挡住后续操作。
- 原通知数据库采用增量迁移，保留收藏、已读、自定日期，并新增内容变化提示。

## 尚不能等同于通过的项目

- SSH 新指纹经用户授权接受，连接时固定匹配；没有把用户授权等同于独立控制台核验。
- SMTP 业务流程使用隔离测试替身验证；上线后真实 SMTP 登录认证通过，发信配置已生效。尚未验收实际邮件到达收件箱。
- DeepSeek 任务协议与权限已测试；上线时校验当前账号模型列表，切换可用模型并用合成文字通过真实 JSON 请求。没有声称实际学生简历输出质量已验收。
- 学校教务成绩使用真实账号的端到端联调尚未进行；验证码、页面变动及学院规则仍需核对。
- 测试覆盖本机 Android 35 模拟器，并未声称覆盖所有品牌手机或 Android 8–15 的全部系统差异。
- Word 中未完整实现的后续细节见《Word方案对照》与《使用与部署说明》，不能将本次 47 项通过理解为完整商业平台全部功能已验收。
