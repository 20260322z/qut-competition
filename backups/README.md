# 加密恢复备份

[下载 2026-09-13 加密备份](qut-private-backup-2026-09-13.zip)

此文件使用 AES-256 ZIP 加密，供项目所有者恢复服务器配置和 Android 发布签名。解密密码没有上传至 GitHub，单独保存在项目所有者电脑桌面的“青理竞赛通-私密备份”文件夹中。

包含服务器访问凭据、当时的后端环境配置和 Compose 配置，以及 Android 发布签名备份。业务数据库和学生资料不包含在内。

使用支持 AES 加密 ZIP 的 7-Zip 或 WinRAR 输入密码解压。外层解密后，签名备份仍为独立 ZIP，按其中说明使用。恢复服务器配置前，应先备份现有配置并检查路径是否适合目标服务器。

旁边的 `.sha256` 文件用于校验下载完整性。此备份已通过逐文件解密校验和错误密码拒绝测试。

普通用户安装、更新 App 无需下载此文件。项目所有者请另外妥善保存解密密码；解密后的文件不得提交至公开仓库。
